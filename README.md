#### Hackathons

At the **Prosus & AISO AI University Games Hackathon 2025**, my team won **3rd place** with [**Gradent**](https://github.com/flatala/gradent), a multi-agent study assistant for assignment analysis, scheduling, progress tracking, and proactive study suggestions. The system used LangChain and LangGraph with a central orchestrator that interpreted user requests and routed them through specialized agent workflows.

At **HackYeah 2023**, my team built [**Animal Tracker**](https://github.com/HackYeah2023-AiR), a finalist lost-pet reporting app with an ML pipeline for animal detection, classification, and report matching. The system used Tiny YOLOv3 to crop animals from uploaded photos, an AlexNet-based dog/cat classifier fine-tuned on additional pet images, and VGG16 embeddings with cosine similarity to match lost and found reports.
